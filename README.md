# 배달의민족 외식배달비 자동조사

**Streamlit · Python · BlueStacks 5 · uiautomator2 · openpyxl**

배달의민족 앱에서 외식배달비, 최소주문금액, 사업자정보, 메뉴 정보를 자동으로 수집하고 기존 Excel 조사표와 비교·기록하는 프로그램입니다. 반복적인 조사와 입력은 자동화하되, 대상처 매칭이나 메뉴 변경처럼 불확실한 결과는 **사람 확인 대상**으로 분류합니다.

최종 사용자 인터페이스는 **Streamlit 웹 대시보드**입니다. 조사 설정부터 진행 현황, 결과 확인 및 Excel 다운로드까지 하나의 화면에서 관리할 수 있습니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 조사 범위 설정 | 특정 행·대상처·주소·지역·복수 지역·조합·전국 전체 |
| 자동 조사 | 배달의민족 앱 검색, 배달유형별 요금 및 사업자정보·메뉴 수집 |
| 실시간 현황 | 진행률, 경과 시간, 상태별 캐릭터, 최근 실행 로그 |
| 안전 중단·이어하기 | Excel 저장 완료 지점에서 중단 요청 처리, 완료 주소지 재조사 최소화 |
| 사람 확인 | 유사·중복 대상처, 대체 대상처, 메뉴·주소 확인, 기술 실패 등 검토 |
| 결과 조회 | 조사 결과 검색·필터링, Excel 다운로드, 전체 상세 로그 조회 |

## 시작하기

### 1. 실행 환경

- **Windows**, Python, BlueStacks 5 Pie64
- BlueStacks에 설치 및 로그인된 **배달의민족 앱**
- BlueStacks **ADB 활성화**
- 검증된 BlueStacks 화면 크기: **900 × 1600**

### 2. 설치

저장소를 내려받은 뒤 프로젝트 폴더에서 의존성을 설치합니다.

```powershell
python -m pip install -r requirements.txt
```

캐릭터 이미지는 프로젝트의 `assets/` 폴더 또는 프로젝트 상위 디렉터리의 `배민_ui_png/` 폴더에서 불러옵니다. 이미지가 없으면 일부 캐릭터가 표시되지 않을 수 있지만, 조사 엔진 자체와는 별개입니다.

### 3. 실행

```powershell
python -m streamlit run app.py
```

브라우저에 표시되는 대시보드의 **Settings**에서 Excel 조사표와 조사 조건을 설정합니다.

### 4. 조사 진행

1. **Settings → 새 조사 시작**에서 원본 Excel 파일을 업로드합니다.
2. 조사 월과 범위(지역·조합·전체 등)를 선택합니다.
3. **조사 대상 미리보기**로 대상처 수와 선택 범위를 확인합니다.
4. **실제 조사 시작**을 누르면 BlueStacks에서 자동조사가 실행됩니다.
5. **Home**에서 진행률과 로그를 확인하고, 종료 후 **Results**에서 결과를 조회하거나 Excel을 다운로드합니다.

작업이 중단된 경우 **Settings → 기존 작업 이어하기**에서 이전 작업을 선택합니다. 전체·조합 조사에서는 Excel에 저장된 완료 주소지를 기준으로 이어하기를 지원하며, 저장되지 않은 주소지는 다시 조사될 수 있습니다.

> 안전 중단 버튼은 즉시 프로세스를 강제 종료하지 않고, 조사 엔진의 **Excel 저장 완료 지점**에서 중단 요청을 처리합니다.

## 대시보드 구성

| 화면 | 주요 기능 |
|---|---|
| **Home** | 실시간 진행 현황, 경과 시간, 사람 확인 건수, 최근 로그, 안전 중단, 결과 다운로드 |
| **Settings** | 새 조사, 기존 작업 이어하기, Excel 업로드, 조사 범위 설정 및 미리보기 |
| **Results** | 조사 결과 전체 조회, 검색 및 Excel 다운로드 |
| **Results → 사람 확인** | 검토가 필요한 대상처와 확인 사유 조회 |
| **Results → 상세 로그** | 실행 기록 선택, 전체 로그 조회 및 실시간 갱신 |

## 조사 결과 및 데이터 관리

조사 결과는 Excel 파일에 기록됩니다.

| Excel 시트 | 내용 |
|---|---|
| `조사자료(rawdata)` | 대상처별 조사값, 전월 비교 및 변경사항 |
| `조사로그` | 조사 판정, 상태 코드, 사람 확인 사유와 후보 정보 |
| `자동조사진행` | 전체·조합 조사의 주소지별 저장 완료 상태 |

주요 판정에는 `FOUND`, `MULTIPLE_MATCH_REVIEW`, `SAME_STORE_REVIEW`, `REPLACEMENT_NEEDED`, `TECHNICAL_FAIL` 등이 있습니다. 앱 연결 실패나 검색 오류를 대상처 폐업으로 임의 판정하지 않으며, 추가 검토가 필요한 항목은 별도로 기록합니다.

조사 입력 데이터·결과 Excel·실행 로그 및 작업 상태는 로컬 `data/`, `output/`, `logs/` 등에 보관됩니다. 이 파일들은 Git 업로드 대상에서 제외합니다.


**개발 자료:** 저장소에 포함된 `run_survey_template.ipynb`와 `baemin_delivery_fee_survey.ipynb`는 개발·검증 과정에서 사용한 참고 노트북입니다. **Streamlit 프로그램을 실행하는 데는 필요하지 않습니다.**

| 지표 | 결과 |
|---|---:|
| 조사 대상처 | **745개** |
| 조사 지역 | 17개 |
| 조사 조합 | 6개 |
| 자동조사 실행 시간 | **3시간 30분 18초** |

기존 수작업 조사에 약 **16시간**이 소요된다는 추정치를 기준으로, 자동 수집·입력 단계의 시간은 약 **78.1% 단축**되었습니다. 단, 수작업 시간은 추정치이며 **사람 확인 51건의 후속 검토 시간은 자동조사 실행 시간에 포함되지 않습니다.** 모든 대상처가 자동 확정되었다는 의미도 아닙니다.

## 사용 시 유의사항

- 실제 앱 조사에는 Windows·BlueStacks 환경이 필요하며, 다른 해상도에서는 UI 조작을 재검증해야 합니다.
- 현재 조사표 열 구조는 **2026년 9~12월 기준**이며, 다른 형식의 조사표는 별도 검증이 필요합니다.
- 실행 중 결과 Excel 또는 작업 상태 JSON 파일을 외부 프로그램에서 수정하지 않는 것이 좋습니다.
- 로컬 Excel 원본·조사 결과·실행 로그·개인정보·인증 정보는 저장소에 커밋하지 않습니다.
