# 🛵 배달의민족 외식배달비 자동조사

**Streamlit · Python · BlueStacks 5 · uiautomator2 · openpyxl**

배달의민족 앱에서 배달비, 최소주문금액, 사업자정보 및 메뉴를 조회하고 **Excel 조사표에 결과를 기록하는 자동화 프로그램**입니다. 반복적인 조회·입력 작업을 자동화하고, 결과가 불확실한 대상처는 **사람 확인** 목록으로 분류합니다.

**최종 실행 화면은 Streamlit 대시보드입니다. Jupyter Notebook을 설치하거나 실행할 필요는 없습니다.**

## 처음 사용하는 분을 위한 설치 안내 (Windows)

프로그램 설치가 처음이어도 아래 **1단계부터 순서대로** 따라 하면 됩니다. 컴퓨터에 Python과 BlueStacks가 이미 설치되어 있다면 해당 단계는 건너뛰어도 됩니다.

### 1. Python 설치하기

1. [Python 공식 다운로드 페이지](https://www.python.org/downloads/windows/)에서 **Python 3.12** 설치 파일을 내려받습니다.
2. 설치 화면에 **Add Python to PATH** 또는 비슷한 항목이 보이면 선택한 다음 설치합니다. (설치 프로그램 버전에 따라 표시가 다를 수 있습니다.)
3. 키보드에서 **Windows 키 + R**을 누르고 `cmd`를 입력한 후 Enter 키를 누릅니다. 검은색 창이 나타나면 CMD(명령 프롬프트)입니다.
4. 아래 명령어를 입력하고 Enter 키를 눌러 설치 여부를 확인합니다.

```cmd
python --version
```

`Python 3.12.x`와 같은 버전이 나오면 준비됐습니다. 명령어를 찾을 수 없다는 메시지가 나오면 CMD를 닫았다가 다시 열고 확인하세요. 그래도 안 되면 Python 설치와 PATH 설정을 확인해야 합니다.

### 2. BlueStacks 설치 및 준비하기

1. [BlueStacks 5 공식 홈페이지](https://www.bluestacks.com/ko/index.html)에서 BlueStacks 5를 설치합니다.
2. **Pie 64비트 인스턴스**를 실행하고, Play 스토어에서 **배달의민족** 앱을 설치하여 로그인합니다.
3. BlueStacks의 **설정(톱니바퀴) → 고급 → Android Debug Bridge(ADB)** 를 켜고 **변경사항 저장**을 누릅니다. ([공식 ADB 설정 안내](https://support.bluestacks.com/hc/ko/articles/23925869130381-BlueStacks-5%EC%97%90%EC%84%9C-Android-Debug-Bridge-%ED%99%9C%EC%84%B1%ED%99%94%ED%95%98%EB%8A%94-%EB%B0%A9%EB%B2%95))
4. 조사에 사용하도록 검증된 화면 크기는 **900 × 1600**입니다. 다른 해상도라면 먼저 소수 대상처로 테스트해 주세요.

> 조사할 때는 BlueStacks와 배달의민족 앱이 실행 가능한 상태여야 합니다.

### 3. 프로그램 파일 받기

1. GitHub 저장소 상단의 **Code → Download ZIP**을 누릅니다.
2. 내려받은 ZIP 파일을 우클릭하여 **압축 풀기**를 선택합니다.
3. 압축을 푼 폴더에서 `app.py`, `baemin_survey.py`, `streamlit_worker.py`, `requirements.txt` 파일이 있는지 확인합니다.
4. 캐릭터 이미지를 가지고 있다면 같은 폴더 안에 `assets` 폴더를 만들고 PNG 파일을 넣습니다. 캐릭터가 없어도 조사 기능 자체는 사용할 수 있습니다.

### 4. 필요한 라이브러리 설치하기

1. 압축을 푼 **프로젝트 폴더를 파일 탐색기에서 엽니다.**
2. 파일 탐색기 **맨 위 주소 표시줄**을 클릭하고, 주소 대신 `cmd`를 입력한 뒤 Enter 키를 누릅니다.
3. 해당 폴더 위치로 열린 검은색 창에 다음 명령어를 복사해 붙여넣고 Enter 키를 누릅니다.

```cmd
python -m pip install -r requirements.txt
```

설치는 처음 한 번만 하면 됩니다. 오류 없이 명령어 입력 위치가 다시 나오면 다음 단계로 진행할 수 있습니다.

### 5. 프로그램 실행하기

앞 단계에서 열어둔 CMD 창에 아래 명령어를 입력합니다.

```cmd
python -m streamlit run app.py
```

브라우저가 자동으로 열리면 성공입니다. 열리지 않는다면 CMD에 표시된 `http://localhost:8501` 주소를 복사하여 Chrome 또는 Edge 주소창에 붙여넣으세요.

**프로그램 사용 중에는 CMD 창을 닫지 마세요.** 웹 화면을 종료하고 싶다면 CMD 창에서 `Ctrl + C`를 누르면 됩니다. 조사 중에는 먼저 웹 화면의 **안전 중단**을 이용하세요.

## 실제 조사 사용법

1. **Settings** 메뉴를 엽니다.
2. **새 조사 시작**에서 `.xlsx` 조사표를 업로드합니다.
3. 조사 월과 범위를 선택합니다. 전국을 모두 조사한다면 조사 범위를 **전체**로 설정합니다.
4. **조사 대상 미리보기**에서 대상 수와 목록이 맞는지 확인합니다.
5. 확인란에 체크한 뒤 **실제 조사 시작**을 누릅니다.
6. **Home**에서 진행률, 소요 시간, 최근 실행 로그를 확인합니다.
7. 조사가 끝나면 **Results**에서 결과를 확인하고 **Excel 결과 다운로드**로 저장합니다.

**중단했다가 다시 시작해야 하나요?** Settings의 **기존 작업 이어하기**에서 저장된 작업을 선택하세요. 전체·조합 조사에서는 저장 완료된 주소지를 건너뛰고 이어서 조사할 수 있습니다. 단, 마지막으로 저장되지 않은 주소지는 다시 조사할 수 있습니다.

**조사를 중단하려면?** Home에서 **전체 조사 안전 중단**을 누르세요. 데이터 유실 위험을 줄이기 위해 **다음 Excel 저장 지점 이후 중단**되므로 바로 멈추지 않을 수 있습니다.

### 화면별 기능

| 메뉴 | 할 수 있는 일 |
|---|---|
| **Home** | 진행률·시간·최근 로그 확인, 안전 중단, Excel 다운로드 |
| **Settings** | 원본 조사표 업로드, 조사 조건 설정, 미리보기, 작업 이어하기 |
| **Results** | 전체 조사 결과 조회 및 다운로드 |
| **Results → 상세 로그** | 조사 실행 기록과 오류 메시지 확인 |
| **Results → 사람 확인** | 자동 확정하지 않은 대상처와 검토 사유 확인 |

## 자주 묻는 질문

**Q. CMD와 PowerShell 중 어느 것을 사용해야 하나요?**  
이 설명서에서는 **CMD(명령 프롬프트)** 를 사용합니다. PowerShell에서도 Python과 Streamlit 실행 명령어는 대부분 동일하지만, 초보자는 위 안내대로 CMD를 사용하면 됩니다.

**Q. `python` 명령어가 실행되지 않아요.**  
Python이 설치되었는지 확인하고 CMD를 다시 열어보세요. Windows의 `py --version` 명령어도 확인할 수 있습니다.

**Q. `No module named streamlit` 오류가 나요.**  
프로젝트 폴더에서 `python -m pip install -r requirements.txt`를 다시 실행해 주세요.

**Q. 캐릭터가 안 보여요.**  
프로젝트 상위의 `배민_ui_png` 폴더 또는 프로젝트 안의 `assets` 폴더에 해당 PNG 파일이 있는지 확인해 주세요. **이미지 파일 이름도 코드에서 지정한 이름과 같아야** 합니다.

**Q. BlueStacks 연결 오류가 나요.**  
BlueStacks가 실행 중인지, 배달의민족이 설치되어 있는지, **고급 설정의 ADB가 켜져 있는지** 확인하세요. 기본 설치 경로가 아니라면 Settings의 고급 설정에서 설치 경로를 지정합니다.

**Q. 실행 결과는 어디에 저장되나요?**  
조사 결과는 로컬 프로젝트의 `output/` 폴더에, 진행 기록은 `data/`와 `logs/` 폴더에 생성됩니다. 이 폴더는 GitHub 업로드 대상이 아닙니다.

```text

├── app.py                  # Streamlit 최종 실행 화면
```

`run_survey_template.ipynb`, `baemin_delivery_fee_survey.ipynb`는 **개발 과정의 참고 자료**입니다. 일반 사용자는 열 필요가 없습니다.
