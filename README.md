# 배달의민족 외식배달비 자동조사

**Python · Jupyter Notebook · BlueStacks 5 · uiautomator2 · openpyxl**

배달의민족 앱에서 외식배달비, 최소주문금액, 사업자정보 및 메뉴 정보를 자동으로 수집하고, 기존 Excel 조사표와 비교하여 기록하는 자동화 프로젝트입니다.

반복적인 수집·입력 작업은 자동화하고, 대상처 매칭이나 대체 메뉴 선정 등 불확실한 판단은 사람이 검토하도록 설계했습니다.

## Streamlit 대시보드 실행 (Windows)

기존 Jupyter 실행 방식 외에 Streamlit 웹 UI를 제공합니다.

1. `python -m pip install -r requirements.txt` 로 의존성을 설치합니다.
2. 프로젝트 폴더 바깥의 `배민_ui_png/` 폴더에 UI용 PNG 캐릭터 파일을 놓거나, 프로젝트 내부 `assets/` 에 넣습니다. **이미지는 코드와 별도이며, GitHub에 없는 경우 캐릭터가 표시되지 않습니다.**
3. BlueStacks 5에서 배달의민족 로그인과 ADB 설정을 준비합니다.
4. `python -m streamlit run app.py` 를 실행합니다.
5. Settings에서 새 조사표 업로드 → 대상 미리보기 → 실제 조사 시작 또는 기존 작업 이어하기를 선택합니다.

기능: Home 진행률·경과 시간·안전 중단, Results Excel 결과 조회·다운로드, 사람 확인 검토 목록, 실시간·전체 상세 로그. 안전 중단은 엔진의 Excel 저장 완료 로그가 나온 후 적용되며 즉시 종료가 아닙니다.

> 주의: **실제 조사 중인 컴퓨터의 로컬 파일을 ChatGPT가 직접 Git에 동기화할 수는 없습니다.** 조사 Excel, 개인정보, 로그, 실행 기록은 GitHub에 올리지 마세요. 작업 상태 JSON은 현장 파일이 최종 기준입니다.

## 🚀 Quick Start | 자동조사 실행 방법

> **Jupyter로 실행할 때는 `run_survey.ipynb`, 웹 화면으로 실행할 때는 `app.py`를 사용합니다.**
>
> `baemin_survey.py`는 조사 함수가 구현된 Python 모듈입니다. 사용자는 핵심 코드를 직접 수정하지 않고, **실행 노트북에서 조사 조건만 입력**하면 됩니다.

### 1. 프로젝트 다운로드

GitHub 저장소에서 `Code → Download ZIP`을 선택하고 압축을 해제합니다.

Python과 BlueStacks 5가 설치된 Windows 컴퓨터를 기준으로 합니다.

프로젝트 폴더에서 필요한 Python 라이브러리를 설치합니다.

```bash
python -m pip install -r requirements.txt
```

Jupyter Notebook이 설치되어 있지 않다면 별도로 설치해야 합니다.

BlueStacks 5에서 배달의민족 앱에 로그인하고, ADB 기능을 활성화한 뒤 앱을 실행할 수 있는 상태로 준비합니다.

### 2. 실행 노트북 준비

1. 프로젝트 폴더의 `run_survey_template.ipynb`를 복사합니다.
2. 복사본 이름을 **`run_survey.ipynb`**로 변경합니다.
3. Jupyter Notebook에서 `run_survey.ipynb`를 엽니다.
4. 설정 셀에서 조사 조건을 입력합니다.

| 파일 | 역할 |
|---|---|
| **`run_survey.ipynb`** | 실제 조사 실행 및 조사 조건 설정 |
| `run_survey_template.ipynb` | GitHub 배포용 실행 노트북 |
| `baemin_survey.py` | 데이터 수집, Excel 입력, ADB 연결 등 핵심 함수 |
| `baemin_delivery_fee_survey.ipynb` | 초기 개발 코드 보존 |
| `requirements.txt` | Python 라이브러리 목록 |

`run_survey.ipynb`는 개인별 Excel 경로가 포함되는 로컬 실행 파일이며, GitHub 업로드 대상에서 제외됩니다.

### 3. 조사 조건 설정

`run_survey.ipynb`의 설정 셀에서 다음 항목을 수정합니다.

```python
from baemin_survey import run_survey

# 1. 조사 월 및 Excel 경로
MONTH = 10
INPUT_FILE = r"C:\survey\input.xlsx"
OUTPUT_FILE = r"C:\survey\output.xlsx"

# 2. 조사 대상
MODE = "지역"
TARGET = "세종"

# 3. 실행 설정
NEW_SURVEY = False
PREVIEW_ONLY = True
BLUESTACKS_DIR = r"C:\Program Files\BlueStacks_nxt"
```

| 설정값 | 설명 |
|---|---|
| `MONTH` | 조사 월 (현재 9~12월 지원) |
| `INPUT_FILE` | 원본 Excel 조사표 경로 |
| `OUTPUT_FILE` | 결과 Excel 저장 경로 |
| `MODE` | 조사 범위 선택 방식 |
| `TARGET` | 선택할 행 번호, 주소, 지역 등 |
| `NEW_SURVEY` | 신규 조사 또는 기존 조사 이어하기 |
| `PREVIEW_ONLY` | 실제 조사 실행 여부 |
| `BLUESTACKS_DIR` | BlueStacks 설치 폴더 경로 |

위 Excel 경로는 예시이며 실제 파일 경로로 변경해야 합니다.

### 4. 조사 범위 선택

`MODE`와 `TARGET`을 변경하면 다양한 단위로 조사를 실행할 수 있습니다.

| 조사 방식 | MODE | TARGET |
|---|---|---|
| 특정 행 1개 | `"행"` | `[486]` |
| 여러 행 | `"행"` | `[486, 487, 488]` |
| 특정 대상처 | `"대상처"` | `"대상처명"` |
| 특정 조사 주소 | `"주소"` | `"조사표 H열의 정확한 주소"` |
| 특정 지역 | `"지역"` | `"세종"` |
| 여러 지역 | `"여러지역"` | `["서울", "세종"]` |
| 지정 조사 조합 | `"조합"` | `[2, 4]` |
| 전국 전체 조사 | `"전체"` | `None` |

행 번호는 Excel의 실제 행 번호를 사용합니다. 대상처명이 중복된다면 행 번호로 선택하고, 조사 주소는 원본 조사표의 H열 값과 정확히 일치해야 합니다.

**전국 전체 조사 예시**

```python
MODE = "전체"
TARGET = None
```

#### 기존 6개 조사 조합

| 조합 | 조사 지역 |
|---|---|
| 1 | 경기 |
| 2 | 서울, 강원, 인천 |
| 3 | 경남, 전남, 제주 |
| 4 | 경북, 충북, 세종 |
| 5 | 부산, 광주, 대구, 울산 |
| 6 | 전북, 충남, 대전 |

### 5. 미리보기 및 실제 조사 실행

**① 조사 대상 미리보기**

```python
PREVIEW_ONLY = True
```

선택한 조사 월, 지역, 대상처 개수 및 결과 파일 경로를 확인합니다.

미리보기에서는 배달의민족 앱을 조작하거나 결과 Excel을 수정하지 않습니다.

**② 실제 자동조사 실행**

```python
PREVIEW_ONLY = False
```

설정 셀을 실행한 후 다음 실행 셀을 실행합니다.

```python
run_survey(
    month=MONTH,
    input_file=INPUT_FILE,
    output_file=OUTPUT_FILE,
    mode=MODE,
    target=TARGET,
    new_survey=NEW_SURVEY,
    bluestacks_dir=BLUESTACKS_DIR,
    preview_only=PREVIEW_ONLY
)
```

실행 후에는 설정한 대상처를 순서대로 조사하고, 수집 결과를 Excel에 저장합니다.

**주의:** Jupyter에서 `Restart & Run All`을 선택하면 설정에 따라 실제 조사가 시작될 수 있습니다. 실행 전 `PREVIEW_ONLY` 값을 확인하세요.

### 6. 신규 조사 및 이어하기

| 설정 | 동작 |
|---|---|
| `NEW_SURVEY = True` | 새로운 조사 시작 |
| `NEW_SURVEY = False` | 기존 조사 결과 유지 및 이어하기 |

`NEW_SURVEY = True`로 실행하면 기존 결과 파일의 초기화 절차가 진행될 수 있습니다. 기존 파일이 있는 경우 백업 및 초기화 확인 절차를 거칩니다.

기존 조사 결과를 보존하려면 별도의 출력 파일명을 사용하세요.

전체 조사와 조합 조사는 **주소지별 중간 저장 및 이어하기**를 지원합니다.

- 완료된 조사 주소지는 Excel에 기록됩니다.
- 조사 중단 후 `NEW_SURVEY = False`로 재실행하면 저장 완료된 주소지를 건너뜁니다.
- 이어하기는 개별 업체가 아닌 **주소지 단위**로 이루어집니다.
- 저장이 완료되지 않은 주소지는 재조사될 수 있습니다.

### 7. 조사 결과 확인

조사 결과는 Excel 파일에 자동 저장됩니다.

| 시트 | 저장 내용 |
|---|---|
| `조사자료(rawdata)` | 배달비, 최소주문금액, 변동사항 등 |
| `조사로그` | 대상처별 조사 결과, 판정 및 사람 확인 정보 |
| `자동조사진행` | 전체·조합 조사의 주소지별 진행 상태 |

전체 조사 및 조합 조사에서는 결과 파일에 `_자동전체조사.xlsx`가 붙습니다.

예시: `output_자동전체조사.xlsx`

행 또는 대상처 재조사의 경우 동일한 이름의 전체 조사 결과 파일이 존재하면 해당 파일에 결과를 반영할 수 있으므로 실행 로그에 표시되는 실제 저장 경로를 확인해야 합니다.

조사로그에는 검색 후보, 신규 대상처 추천, 메뉴 후보, 사람 확인 사유 등 검토에 필요한 정보를 기록합니다.

### 조사 상태 구분

검색 결과가 여러 개이거나 앱 오류가 발생했다고 해서 대상처가 존재하지 않는 것으로 판단하지 않습니다.

대표적으로 다음 상태를 구분합니다.

| 상태 코드 | 의미 |
|---|---|
| `FOUND` | 대상처 확인 |
| `MULTIPLE_MATCH_REVIEW` | 대상처 검색 후보 여러 개 |
| `SAME_STORE_REVIEW` | 동일 대상처 여부 검토 |
| `REPLACEMENT_REVIEW` | 대체 대상처 적합성 검토 |
| `REPLACEMENT_NEEDED` | 신규 대상처 탐색 또는 대체 필요 |
| `PARTIAL_REVIEW` | 일부 조사정보 확인 필요 |
| `TECHNICAL_FAIL` | 앱·연결 등 기술적 오류 |

사람의 판단이 필요한 경우 관련 정보를 조사로그에 남기며, 확인되지 않은 결과를 임의로 확정하지 않도록 설계했습니다.

기존 수작업 조사는 전국 대상처의 배달비와 사업자정보를 직접 조회하고 Excel에 입력하는 방식으로, **하루 8시간 근무 기준 약 2일(16시간)**이 소요된 것으로 추정됩니다.

기존 조사 엔진과 실행 환경을 분리하여 조사 월, 대상처, 지역이 변경되어도 핵심 함수를 재사용할 수 있도록 구성했습니다.

## Excel 원본 조사표 구조

원본 조사 시트는 `조사자료(rawdata)`이며, 대상처 데이터는 8행부터 시작합니다.

| 열 | 내용 |
|---|---|
| D | 업종 |
| E | 조사 품목 |
| F | 지역 |
| H | 배달 기준 주소 |
| I | 대상처명 |
| J | 대표자명 |
| K | 사업자주소 |
| L | 기존 조사 메뉴 |

월별 결과 열은 `baemin_survey.py`의 월별 열 매핑 함수에 따라 처리합니다.

현재 모듈은 **9~12월 조사표 구조를 기준으로 지원**합니다.

## 실행 환경 및 주의사항

- 운영체제: Windows
- Python 및 Jupyter Notebook
- BlueStacks 5 Pie64
- 배달의민족 Android 앱
- `uiautomator2`, `openpyxl`
- 검증된 BlueStacks 화면 크기: **900×1600**

BlueStacks ADB 연결은 조사 실행 시 자동으로 준비합니다. 다만 앱 실행 상태, ADB 활성화 여부 및 설치 경로는 사용자 환경에 맞아야 합니다.

다른 컴퓨터나 다른 화면 크기에서는 실제 조사 전에 일부 대상처를 대상으로 정상 작동 여부를 확인해야 합니다.

전체·조합 조사는 기존 745개 대상처 구성의 조사표를 기준으로 하며, 다른 규모의 조사표는 부분 조사 모드를 활용해야 합니다.

실제 조사 Excel, 개인 경로, 개인정보가 포함된 실행 출력 및 조사 결과 파일은 공개 저장소에 업로드하지 않아야 합니다.
